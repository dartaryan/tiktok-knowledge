## תקציר

הסרטון מציג את vibeui.online, ספרייה חינמית של 92 פרומפטים מוכנים להעתקה לסקשנים ולייאאוטים של UI (auth, pricing, hero, bento, dashboards ועוד) — מיועדים להזנה ישירה לכלי AI-coding כמו Cursor, Lovable ו-Bolt. כל פרומפט מתאר את המבנה המבני של הסקשן (לא את הסגנון הויזואלי), ומיועד לשימוש בשילוב עם סקרינשוט של עיצוב רצוי. רלוונטי לפרויקט TailorPlayed לבניית ממשקים צרכניים מהירים עם Tailwind ו-React.

## תובנות מפתח

- vibeui.online מכיל 92 פרומפטים מבניים (layout prompts) — לא קומפוננטות קוד אלא תיאורי layout שמוזנים ל-AI builder יחד עם סקרינשוט של הסגנון הרצוי
- הספרייה עצמה חינמית, אך הכלי המשלים GlowUp UI (שממיר פרומפט + סקרינשוט לממשק) הוא שירות נפרד שייתכן ואינו חינמי לחלוטין — יש לבדוק
- חלופה בתשלום: vibecodecomponents.com מציע 200+ פרומפטים premium לפרויקטי Lovable, Cursor ו-Bolt
- גישה מעניינת לשימוש ב-TailorPlayed: במקום לתכנן UI מאפס, לבחור פרומפט מבני מהספרייה ולשלב עם DaisyUI/Tailwind לעיצוב סופי
