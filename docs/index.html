Lenis — Lightweight Smooth Scroll Library with GSAP Integration

  • האינטגרציה עם GSAP ScrollTrigger מתבצעת על ידי חיבור lenis.on('scroll', ScrollTrigger.update) והוספת lenis.raf לתוך gsap.ticker
